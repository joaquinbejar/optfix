## Representation comparison (milestone 3)

Measured at commit `6adf034`, where `make bench` reproduces it, with the inputs above: each candidate of `docs/PLAN.md` 4.1 on the same arguments and build profile. "Decimal, binary core" converts in and out of the 64-bit-digit kernel that Q64.64 uses; "decimal, native" runs the same reduction and polynomials as decimal `Fixed` multiplies. Q64.64 is 15% cheaper than the best decimal form, outside the 10% band in which decimal would have won for its exact token conversions (`docs/PLAN.md`, decision log); it is also the more accurate (`docs/precision.md`).
