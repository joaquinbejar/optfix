# Precision

Generated by `make precision` (`optfix/tests/exp_ln_props.rs`); do not edit by hand. Maximum error over 1000000 deterministic samples per row (splitmix64), against a 256-bit reference (`num-bigint` series, itself checked against Python's correctly rounded `decimal` in `tools/reference.txt`). One ulp is `2^-64`, about `5.4 × 10^-20`. `exp` errors are in ulps of `max(e^x, 1)`, a relative bound for results above 1 and an absolute one below; `ln` errors are absolute. The bounds are `EXP_MAX_ERROR_ULPS` and `LN_MAX_ERROR_ULPS`, which the property tests (`make test`) assert over one million random cases each.
